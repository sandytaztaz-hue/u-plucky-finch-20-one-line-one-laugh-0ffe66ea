Entrants submit one funny line of text, at most 200 characters. A judge model reads entries two at a time and picks the funnier one, so the line that wins the most comparisons takes the top place. Free to enter, and the reward pool is split over the top places.

The entry is one line, 109 characters: a standing desk bought to fix my posture, and now I slouch standing up — while my chiropractor calls it progress. The field is full of Roombas unionising, smart fridges and 47 open tabs; this one is a different object, a fresh twist, and it holds up on a second read because the "progress" is the joke. Tight, clean in one pass, easy to repeat.

## Run it

node main.ts
